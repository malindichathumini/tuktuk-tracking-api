## 📋 Description
Real-Time Three-Wheeler (Tuk-Tuk) Tracking & Movement Logging System for Sri Lanka Police

## 🛠️ Technologies Used
- Node.js / Express.js
- MongoDB Atlas
- JWT Authentication
- Swagger UI
- Railway (Deployment)

## 📡 API Endpoints
- POST /api/auth/register
- POST /api/auth/login
- GET /api/provinces
- GET /api/districts
- GET /api/stations
- GET /api/tuktuk
- GET /api/location/live
- GET /api/location/last/:tukTukId
- GET /api/location/history/:tukTukId
